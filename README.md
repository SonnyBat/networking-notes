# Networking Notes

A collection of networking notes created while studying cybersecurity & Cisco.

These notes cover fundamental networking concepts required for security operations, penetration testing, and system administration.

## Topics Covered

- IP Addressing
- Network Topologies
- Network Devices
- Subnetting
- ARP
- DHCP
- OSI Model
- TCP vs UDP
- Networking Protocols

## Purpose

Understanding networking is essential in cybersecurity because security professionals need to understand how systems communicate, how data travels, and where vulnerabilities can exist.
